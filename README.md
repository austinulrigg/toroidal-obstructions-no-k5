# Toroidal Obstructions with No K5 Minor

This repository accompanies the paper "Toroidal Obstructions with No K5 Minor" by Austin Ulrigg. It holds the genus computations of Appendix A of the paper, and the programs described there.

The folder `genus` holds the genus computations. Both PAGE and multi_genus compute the genus of the 74 obstructions T1, ..., T74 (Table 1). multi_genus computes the genus of the 312,410 nontoroidal graphs, up to isomorphism, that the enumerations of the supplemental data use without another certificate (Table 2). The results, with the running times, are in `genus/results/TABLES.md`, and `genus/README.md` says how to run the computation again.

The supplemental data of the paper (the items O1–O4, W1–W21, R1–R11, E1–E34, TO1 and TO2 cited in the text) are published separately.
