# Toroidal Obstructions with No K5 Minor

Supplement to *Toroidal Obstructions with No K5 Minor* by Austin Ulrigg.

[O1](supplemental_data/no_K5_obstructions/O1.json) lists the 74 toroidal minor obstructions with no $K_5$ minor. [TO1](supplemental_data/no_K5_topological_obstructions/TO1.json) gives the full list of 381 topological obstructions with no $K_5$ minor, including those 74. [N1](supplemental_data/new_obstructions/N1.json) lists the 120 topological obstructions in the author’s November 2026 catalogue that are absent from the Myrvold–Woodcock collection. Of these, 22 are minor obstructions.
